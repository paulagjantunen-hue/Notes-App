What is this?

This is the demo page for my Notes App, the project that taught me React, Express, SQLite, and the true meaning of emotional resilience. The actual app runs in GitHub Codespaces, so this page shows screenshots, instructions, and everything you need to understand or test it.

Features

  • Write notes
  • Save notes
  • Search notes

How To Run the App

The app runs entirely in GitHub Codespaces. Here's the short version:

Backend (Port 3000)

cd backend
npm install
node server.js

Frontend (Port 5173)

cd frontend
npm install
npm run dev

Open the URL Codespaces gives you. If it screams "Could not connect to the notes server," make sure port 3000 is public.
